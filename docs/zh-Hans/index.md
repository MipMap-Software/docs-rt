## 概览

### 欢迎使用 MipMap RT

[MipMap RT](https://www.mipmap3d.com/products/mipmap-rt) 运行在大疆妙算 3 上，随无人机一同作业。航线飞行过程中可实时生成二维正射影像；航线结束后，返程阶段自动执行后处理二维优化和三维重建。支持有网络和无网络环境下的成果预览与导出。空三、二维地图和三维模型均全自动完成，无需人工交互。

### 特点

- **全自动重建**：自动完成二维地图、空中三角测量和三维模型重建。
- **起飞即出图**：执行航线任务时实时生成二维正射影像，出图帧率约为 2 秒/帧。
- **落地即导出**：在返航时自动执行二维成果优化和三维重建，飞行器降落后等待任务完成即可导出所有二、三维成果。
- **不依赖网络**：无论有没有网络均可进行成果的实时预览与导出


### 硬件

| 类型 | 支持范围 |
| --- | --- |
| 计算平台 | 大疆妙算 3 |
| 飞行器 | DJI M4 系列、DJI M4D 系列、DJI M400 |
| 相机负载 | DJI H30、DJI H30T  |

相机型号由软件自动读取，影像在飞行过程中实时拉取。

### 处理流程

1. **影像实时获取**：拉取飞行器拍摄的影像。
2. **正射影像实时生成**：航线执行期间持续生成二维正射影像。
3. **成果传输**：实时传输重建成果到服务器或地面遥控器。
4. **二维成果优化**：航线结束、飞行器返程时，自动优化二维成果。
5. **三维重建**：同一返程阶段自动进行后处理三维重建。

### 成果浏览

- **云端渲染**：有网络时在任意联网设备登录[成果查看网站](https://www.mipmap3d.com/realtime/#/)即可以查看二、三维重建成果。
- **本地渲染**：没有网络时，只需在遥控器中下载配套的 APP（[MipMap RT Viewer](https://www.mipmap3d.com/download/rt)），即可在遥控器中查看所有成果。

### 成果输出

| 成果 | 格式与用途 |
| --- | --- |
| 空三成果 | BlockExchange XML，可导入其他软件继续使用 |
| 稠密点云 | LAS 、PLY精细点云 |
| 网格模型 | Cesium 3D Tiles（b3dm）、OSGB 层次细节模型 |
| 二维地图 | GeoTIFF 格式的数字正射影像（DOM）和数字表面模型（DSM） |
| 二维地图瓦片 | 切片后的多层 DOM、DSM 瓦片，用于流畅渲染 |
